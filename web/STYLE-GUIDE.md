# GiftWise AI 视觉规范

当前范围：第一页品牌首屏与第二页「怎么运行」；后四屏待用户补充设计（**2026-10-31 时点注**：`index.html` 现已有 **6 个** `data-landing` 区块）。首屏视觉权威为用户提供的1672×941参考图及确认：暖白、大黑字、哑光黑色三维礼盒、红蓝缎带；中文标题「让心意，送得刚刚好」。第二屏按用户桌面三列草图与手机三行草图实现。

首屏副标题由用户指定：「准备礼物的人，先感到幸福。」分为两行，放在主标题与产品说明之间。

桌面透明礼盒从首屏顶部80px定位，去除了原素材上方的空白后保持主体靠上；按浏览器可用高度缩放（306–476px），让较矮窗口也能看到礼盒全貌。手机和平板采用上文下图，图片容器占满页面宽度，按1672:941自然排布，不固定在小画框内。

桌面礼盒以右上角为锚点放大13%；手机和平板使用独立的全宽布局，不套用桌面缩放。导航上下内边距收窄，桌面72px最低高度，手机88px；标题区同步上移，所有点击区域仍至少44px。

两屏衔接收紧：首屏桌面最低高度改为min(50vw,760px)，文字区底部留白64px；第二屏顶部留白桌面/平板40px、手机32px。下滑入口移除「看看怎么选」可见文字，仅保留44px点击区域中的向下箭头与可访问名称。

## 第二屏：怎么运行

桌面与768px平板：文字在上、礼盒在下的三列，无卡片容器。依次说明输入已知信息、AI三方案与独立规则校验、明确选择后才生成呈现。最后一步常驻「目标设计 · Dify尚未实现此阶段」。三只礼盒为打开状态，盒盖错落在后，红/蓝/红缎带自然落在底部。素材透明，沿用首屏哑光黑纸盒与缎面光泽；不添加商品或模型能力证据。

开盒素材修订：盒身是一体连续侧壁，开口只留纸板厚度，移除闭合盖状上沿与横向接缝。蓝盒的盖子平放偏左，右侧红盒的盖子斜靠右侧，三盒朝向有所差异；每盒的丝带由单侧松垂，底部不对称落地。手机闭合素材将两只红盒拉高至与蓝盒接近的盒身与蝴蝶结高度，统一挺拔比例。

电脑端第二屏改为最大1200px的内容区：h2为40px、h3为22px、正文14px。三列文字居中于各自礼盒，说明区同高176px、共用起点，盒图等宽同基线；缩小元素而不放大空白。手机端仍为左文右盒；闭合盒丝带保持扎紧和短带尾，三盒在朝向、蝴蝶结与带尾上允许轻微差异，避免机械复制感。

767px及以下：三行列表；每行左侧圆形编号，中间标题说明，右侧88px闭合礼盒。用同色闭合素材替代桌面开盒素材，与用户手机草图一致。序号表达真实运行顺序，不作为装饰。语义使用有序列表与h3。

两套素材均由内置imagegen按用户草图及首屏材质参考制作，完整提示在本聊天工具调用中留存。各为**2171**×724三联透明图，以最高质量WebP嵌入landing.css，使用三个位置裁切显示，不新增仓库图片文件。桌面缎带图连续排列，手机只取单盒缩略图；不增加入场或悬停动画。

## 首屏与交互

桌面保留参考的左文右图、两行标题、无卡片容器与不对称礼盒构图。平板与手机改为上文下图，不缩小整张桌面截图。顶部按钮为胶囊，主 CTA 为大圆角矩形，下滑提示为文字按钮；触控尺寸至少 44px。主按钮具备默认、hover、active、focus-visible、disabled 状态。鼠标悬停状态仅在支持 hover 的设备启用。

正文与背景颜色计算对比度应不低于 4.5:1。首屏仅做 240ms、8px 的文字位移动效，内容始终可见；reduced-motion 关闭入场与平滑滚动。跳转链接指向流程挂载点，键盘锚点跳转后移动焦点。

## 诚实性与素材

`#mode-flag` 直接写入 HTML，首帧常驻吸顶可见，不等 API 返回。`#hero-flag` 保留接入脚本的数据来源语义，但移除历史的 Dify 是否发布断言，仅描述当前 mock 界面。主视觉为 AI 重制的品牌概念图，不是商品、价格、库存或模型能力证据。后续包装、配色、贺卡及赠送指南须标为目标设计，不能据 mock 呈现推断 Dify 已实现。

主视觉由内置 imagegen 依据用户参考图制作并按圈选修正：每个盒子仅一种丝带颜色、连续盒盖接缝、可信的缎带交叠；构图与光影尽量保持。最新版本继续通过内置 imagegen 去掉整个棚拍背景，输出真正的透明alpha，仅保留礼盒、丝带与轻微接触阴影。去掉矩形底色、混合模式与渐变遮罩，让真实轮廓直接融入页面。以原生1672×941图编码最高质量WebP，不增加像素或伪造超分辨率。

透明图片**已外置**为 `web/public/img/image-1..3.webp`（合计 **348,480 B**），`landing.css` **24,981 B**、内联 `data:image` **0 处**（原方案「以最高质量 WebP data URI 嵌入、约 916 KB」已废弃；拆分记录见 `web/REPORT-WEB-001.md:110`），比先前带背景WebP更小，保留缎带和盒盖细节。后续如获素材目录授权，应拆分图片以独立缓存。

生成提示概要：复刻参考礼盒金字塔，哑光黑盒、红/珊瑚/深蓝缎带、暖白棚拍背景、左侧留白；删除页面文字与导航；修复每个盒体、盒盖、丝带的穿插、融化边角及红蓝混用。精确提示与输出由本聊天内置工具调用留存。
