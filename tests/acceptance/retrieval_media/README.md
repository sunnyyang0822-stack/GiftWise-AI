# 检索与图像独立验收入口设计

当前只交付测试准备，不执行被测业务。本目录由本轮 QA 单独维护；PR #51 的 `nov01_revision`、`final_qa_1031` 与历史报告均不修改。开工时两个新增目录均不存在，本轮没有启动业务测试进程；本地独立worktree不共享其他工作树的测试文件，不得把其他线的开发自测复制为独立验收。

`build_assets.py` 是可审阅测试设计源，输出 `matrix.json`（逐项输入/步骤、预期、执行前提、层次、证据、对齐项）和 `fixtures.json`（全虚构离线数据）。其中 scenario/group/layer 等是 **QA描述字段，不是业务接口字段**。商品和媒体信封使用后台 PR #61 提交的契约字段；正式 API 路由、任务 ID 和状态尚未冻结，故不实现猜测字段的 HTTP adapter。

仅资产自检入口（仓库根目录）：

```text
python tests/acceptance/retrieval_media/build_assets.py
python tests/acceptance/retrieval_media/run_prepare.py --out docs/test-reports/retrieval-media/runs/<全新运行名>
```

自检只证明矩阵和夹具可复现、ID绑定和设计边界正确，不证明业务代码通过。输出业务结果全部 BLOCKED，不会将资产PASS写成业务PASS。证据目录必须全新，禁止覆盖；建议将 stdout/stderr 以原始字节分别保存，并记录外层命令退出码。

## 实现交付后的执行入口

尚未编写实际业务驱动；待契约/实现交付后在本目录增加相应 runner，不更改开发自测或旧QA断言。执行顺序：

1. PM提供锁定集成SHA、三线交付及契约固定内容；独立worktree核对业务文件哈希。先确认旧QA前端阻断缺陷在该SHA的状态，不沿用旧版本结论。
2. 离线/受控provider：根据真实导出接口映射矩阵，分别输入人工夹具；保存原始响应、错误码/精确路径、调用轨迹、队列时序和计数。无真实浏览器/价格结论。适用的原规则回归仅在交付后执行。
3. HTTP：专用空闲端口、自起该副本服务、核对静态资源/配置/模式及进程；禁止连接未知实例。API/任务路由以正式契约填写，不自行发明。每项保留请求、HTTP状态、原始body、ID绑定及provider调用数。
4. 浏览器：全新无插件用户配置，普通URL，不注入 `ui_fixture` 替代集成；桌面1440×900、390×844、浏览器200%缩放。记录DOM、屏幕截图、请求与target数量、键盘焦点、文字等价、加载/降级状态。图片下载失败用明确受控故障，不伪装真实服务失败。
5. 真实后台检索：另用专用后台浏览器，无个人配置/Cookie；只对允许公开来源低频小样本执行。先确认来源/访问范围获准，遇验证码/限制停止。记录搜索参数、页面观察时间、SKU/规格数量/条件/来源截图，报告观察价并非结算保证。`.example.invalid`、内网地址与脚本夹具永远不用于真实导航；安全负例只经可观察的拒绝路径/受控DNS测试。
6. 图像真实服务：单独授权后才执行；注明provider版本、参考图支持、来源使用依据、任务数/成本证据。无授权时SKIP，仍可独立验证未配置/失败降级。真实检索、mock、离线夹具、图像服务分别建证据目录/结果，不拼成全链路通过。

未来每项输出包含 case_id、PASS/FAIL/SKIP/BLOCKED、实际输入/期望/实际、基线SHA和脏状态、模式/provider、起止时间、实际命令与退出码、原始证据路径。字段名属于QA报告格式。FAIL必须附最小复现、影响、责任Agent和修复后回归；BLOCKED写清缺交付/契约/权限，SKIP写清未执行原因。真实接口响应不得只凭“没有异常”判PASS。

## 尚待对齐（后台Agent成文，PM确认）

- A01：任务提交/查询/取消业务入口、状态/错误码、任务作用域、队列Q与超时上限、取消后迟到回调及幂等键/有效期；不拿副本中的任意shell作测试入口。
- A02：会员/优惠券/多件价的结构化条件是否仅字符串说明，资格不明确的机器判定；参考区间上端比较的精确输出状态/错误码。
- A03：价格有效期/刷新判据、服务端证据和图片ID过期语义、可允许来源/下载类型大小限制的实际配置。
- A04：`previous_gifts`在当前前后端/工作流的类型、长度和序列化方式；本轮仅使用用户已指定字段名，不推定为字符串还是列表API。空字符串是界面输入夹具。
- A05：包装任务查询/重试幂等约定、未配置与失败边界、图像注释校验错误码和可访问交互；视觉“高清”的尺寸/清晰度门槛与标注重叠允许范围。未有裁决前用人工证据标待对齐，不自行定像素阈值。

所有矩阵条目在PM锁定SHA前维持BLOCKED。安全负例中的危险字符串/地址仅为输入数据；脚本不执行、不访问这些地址。
