Demo是现场真实运行，不预先承诺外部模型或生图一定成功。案例只使用虚构信息：恋人生日、预算800元、下个月准备，并明确确认30天；不使用6–7天样例。上台前由唯一负责人核对服务与版本；演示者不自行重启8903。

**开演示前的配置核对：** 当前冻结进程的可选补抓开关尚未核实，缺少匹配的推荐请求可能间接触发采集。负责人应在上台前核对既有运行配置；未经确认，不能把该请求称作“纯读库、不采集”。不要为此在台上改配置、重启或触发未知补抓。若与冻结纪律冲突，先说明约束，停在能够安全验证的阶段，并明确区分现场状态与历史证据；不以静默写库换取演示完整。
