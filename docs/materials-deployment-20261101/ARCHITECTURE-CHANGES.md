## PPT P04与单独附图三源

1. 旧“本地商品数据增强 / SQLite库优先 / OpenCLI按需页面读取”改为公开文字素材增强推荐；缓存保留observed_at，模型自行结合用户语境做创意延伸，不把历史摘要冒充实时商品。
2. 增加Compshare虚机边界、Nginx公网80、Node24.16内部8787及systemd守护；不加Dify编排、Docker容器、K8s、Redis或本地GPU推理节点。
3. 浏览器→反代→Node与Node→外部模型API使用不同协议标注：前者HTTP，后者HTTPS；不是不买域名就天然有TLS。
4. 推荐阶段的返回边仅三方案/文字依据/校验，不恢复网图抓取、图片槽位或推荐轮询；保留选后媒体状态GET和同源asset边。
5. 把run/analysis/selection/签名密钥标为内存，将SQLite、缓存、媒体任务/图片、审计和账本标为独立落盘；落盘边不能连成“旧会话恢复”。
6. 保留显式选择、全局一次业务修订、文字先返回、仅选后付费生图、unknown不自动重发；图中实体包装为条件分支，体验无实体交付无包装空章。
7. 框图、P04缩图、正式PDF第3页与三源标签一致；编辑SVG/PNG/drawio时以同一文案表驱动。重生成的PNG要检查可读性，不拉伸裁切；原生PPT文本不要整页扁平化。
