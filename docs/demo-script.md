## 五、关键环节的真实操作与命令

### 5.1 主路径：Dify 草稿工作流真实运行（界面操作）

```text
N1 开始/输入 → N2 生成（真实 DeepSeek）→ N3 Code 校验 → N4 分支
   ├─ N4[true]        → N7a → EndA
   └─ N4[repairable]  → N5 真实修订 → N6 重检 → N7b → EndB
```

**必须注意（来自 WF-003 的真实结论）**

- 本租户 1.18.0 上 **`N4` 的 ELSE 分支从未被触发**（B7）。**不要**声称"三分支都验证过"。
- 真实运行的**首次校验错误均为 `FORBIDDEN_TERM`**；**没有自然 `OVER_BUDGET`**，也**没有 `FORBIDDEN_TAG`** 触发证据（B8）。
- **提示词修复之后的修订→再校验路径没有运行时证据**（B9）。现场如被追问，照实说"该路径尚缺运行时证据"。
- **平台级 trace 不可用**（`not_collected`，B6）→ 节点级输出只能来自界面「上次运行」标签页。
- 现场**不要点「发布」**，也不要「创建版本」。

### 5.2 确定性规则校验（真实代码，可现场敲）
