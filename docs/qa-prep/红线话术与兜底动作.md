# 红线话术与兜底动作

> 上场前 5 分钟扫一遍第 1、2 节。

---

## 1. 红线清单：**绝对不能说的话** → 诚实替代

| # | ❌ 不能说 | 为什么致命 | ✅ 诚实替代 |
| --- | --- | --- | --- |
| 1 | "我们已经上云了" / "云上已部署" | 云部署**从未发生**，一问细节（主机规格/IP/账单）立刻穿 | "**能部署、脚本与设计已写好，但按比赛边界未采购、未上传。**" |
| 2 | "价格是实时的" / "接入了商品库" | `business_data_verification: not_verified`，无任何真实数据源 | "价格、库存、送达**均未核实**；方案里的金额是模型给的**区间估算**且已显式标注。" |
| 3 | "和真实模型端到端联调通过" | 浏览器侧**走 mock**，从未联调 | "真实模型运行证据来自 **Dify 控制台**；浏览器侧是 mock，**未做 UI 与真实模型的端到端联调**。" |
| 4 | "测试全绿" / "全部通过" | 对外声明审计**还有 1 项红** | "329 / 275 / 39 / 45 四套全部 OK，合计 **688**；对外声明审计 **15 PASS / 1 FAIL / 1 SKIP**，红的是**跨层 `days=10**20` 分类口径**（两条已闭合：材料哈希、浏览器自查）。" |
| 5 | "parity 全等价" / "JS 与 Python 完全一致" | 只是**样例级**，且还剩 1 条分歧 | "**74 组样例上语义一致（样例级）**；独立 14 条网格上还剩 1 条极端值分类不同。" |
| 6 | "Dify 还没发布" / "工作流还是草稿" | 已发布创建版本；`toolPublished:false` 不是发布判据 | "**已发布并创建版本**（v1 于 2026-10-30 23:04，当前 v2）。" |
| 7 | "健康检查通过就说明服务正常" | `/healthz` **不碰请求路径**——我们实测过它骗过 | "`/healthz` 只证明**进程活着 + 规则版本一致**；服务可用性我们**另测半开正文**。" |
| 8 | "日志粘连修好了"（无证据） | 会被要求现场复现 | "40 并发后日志 44 行、**粘连 0 行**——我复跑过，`docs/qa-prep/tools/verify_delivery_claims.py` 第 3 项。" |
| 9 | "I-2 的线程永久不回收" | 措辞过强，实际会回落 | "线程占用**持续到客户端放弃或进程重启**；客户端关闭后约 **2.5 s** 回落。" |
| 10 | "/metrics 是安全的" | 该端点**完全未鉴权** | "**未鉴权**，所以**默认不暴露**（实测 404）；公网暴露前必须前置反向代理与鉴权。" |
| 11 | "K8s / 多副本 / 弹性伸缩已就绪" | 全部**未做** | "**无编排、无多副本、无弹性伸缩、无资源调度、无分布式状态**——明确登记为未完成。" |
| 12 | "压力测试过了" / "生产容量已验证" | 只有单机基线 | "只有**单机基线**（40 并发、内存 14.45–17.08 MiB）；**云端消耗与跨机延迟未测**。" |
| 13 | 任何**记不准的数字** | 数字类追问会连锁 | "这一条我**不当场编**——未核实，我**当场跑给您看**。" |

### 1.1 允许的句式（口径纪律，只在下列句式里选）

> **在本机真实构建并验证** · **实测** · **未核实** · **未发生**

凡是不属于这四类的表述，都不要说。

## 2. 被问住时的标准动作（三步，不要跳步）

**第一步：明确承认"没背下来"，不要编。**
> "这个数字我没有背下来。我不想给您一个我记不准的数——**我现场跑一下**。"

**第二步：指向两个自证入口（一个命令、一份指南）。**

```bash
# 对外声明审计：一条命令跑完所有对外声明，告诉你红在哪一行、原始输出在哪
python tools/verify_all.py

# 复核指南：每条对外声明 → 一条可跑命令 → 预期输出，红的就是红的
docs/verification/复核指南-2026-10-31.md
```

> "我们做了一份《复核指南》，里面每一条对外声明都对应一条可跑命令和预期输出——**红的它会告诉你红**。"

**第三步：按证据强度分级回答**，三级不要说混：

| 级别 | 句式 | 适用 |
| --- | --- | --- |
| **A · 实测** | "我亲手跑过，输出是……" | 本线复跑过的（镜像四条、四套测试、74 组 parity、59 冒烟） |
| **B · 归档** | "这一条的来源是 X 归档，**本线未复跑**" | 46 探针、40 接入层、模型调用次数、错误码清点、I-2 线程计数 |
| **C · 未核实** | "**未核实**，我现在可以跑给您看" | 单位价格、单任务成本、生产容量、跨机延迟、价格库存 |

## 3. 答不上来时的兜底话术（三句备选，按场合挑）

1. **现场能跑**：
   > "这一条我没背下来，但我们**不需要您相信我的话**——我现场跑一次，输出直接给您看。"

2. **我们知道但没做到**：
   > "这一条我们**没做到**，登记在 PPT 第 8 页右栏「明确未完成」，编号是 **B2-5**。我们把它写出来而不是藏起来。"

3. **超出当前验证范围**：
   > "这个问题**超出我们目前的验证范围**了。我记下来，会后给您一个**带原始输出**的答复——我不想现在给您一个可能是错的说法。"

---

## 4. 一条元纪律

**我们的材料自己会揭自己的短**（`tools/verify_all.py` 会判 FAIL、PPT 第 8 页列 15 条未完成）。
所以**撒谎的收益是负的**：评委只要跑一条命令就能对出来。
**主动披露 = 可信度；被挖出来 = 诚信问题。** 这两者在 15 分的答辩分里差距极大。
