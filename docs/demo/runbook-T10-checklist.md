### ☐ 特别确认：**没有任何地方用了 `timeout` 包 node/python**

```bash
grep -rn "timeout" docs/demo/bin/ 2>/dev/null
```
**期望：没有把 `timeout` 用在 node/python 上的行。**
> ⚠️ 已实测：MSYS 的 `timeout` **杀不掉**原生 `node.exe`。
> `timeout 3 node …` 之后 9 秒心跳仍写了 8 行；对包装进程 `kill -9` 后 node **仍孤儿存活并占住端口**。
> 这会让"加个超时保险"这个动作本身变成故障源。详见 [`failure-modes.md`](failure-modes.md) F4。

## 附录 B：异常速查表

| 现场看到 | 最可能原因 | 立刻做什么 |
| --- | --- | --- |
| 页面 404 / 白屏 | 另一个 Agent 正在写该文件 | `stat` 该文件 mtime；60 秒内→等 1.5 s 重试；仍失败→**切回放页** |
| 服务起不来 / 端口被占 | 上次的孤儿进程 | `bash docs/demo/bin/servers.sh stop` 然后 `start` |
| 命令报 `UnicodeEncodeError` | 控制台不是 UTF-8 | `chcp 65001` + `set PYTHONIOENCODING=utf-8`；来不及就**不要跑该命令** |
| `KeyError: 'result'` | 用了脚本 §5.2 的旧片段 | 改用 `docs/demo/bin/run-rules-layer-demo.py` |
| Dify 打不开 / 一直转 | 网络或额度 | **切模式 C**，照读"本次没有发起新的模型调用" |
| 模型节点 > 8 秒不动 | 模型慢/额度问题 | 停止等待，**切回放页**，照读归档声明 |
| 界面预览打不开 | node 没起或端口变了 | 用 `http://127.0.0.1:8787`（别人那个也可用）或**切回放页** |
| 模拟标识看不清 | 12 px 太小 | 浏览器 `Ctrl` + `+` 放大；仍不行→**不要展示该页**，改用口播 + 回放页 |
| 投影分辨率变了 | 换了输出设备 | 1024×768–1920×1080 实测均无横向溢出，**直接投即可** |
