# P2-2 · 建议在脚本里加"绝不能做的三件事"

**问题**：脚本 §6 讲了"禁止暗示"（诚实性），但没有讲**环境层面的禁令**。
本轮实测出两条会**直接导致现场挂住**的操作。

**建议新增（放 §6 或 §1.1）**：

```markdown
### 绝不能做的三件事（DEMO-001 实测）

1. **不要用 `timeout` 包裹 node/python。**
   已实测：MSYS 的 `timeout 3 node …` 之后，9 秒内心跳仍写了 **8 行**（期望 3 行）；
   对包装进程 `kill -9` 后 node **仍孤儿存活**，心跳继续增长，并**永久占住端口**。
   → 限时请用 `curl -m`；起服务请用 `docs/demo/bin/servers.sh`（PID 文件 + `Stop-Process` 精确回收）。

2. **不要杀掉别人的服务进程。**
   8 条线共用同一工作目录。预演期间 8787 上就有**另一个 Agent 的** mock 实例
   （`runs` 计数 56→95 持续增长，说明在活跃使用）。
   → 自己的端口被占就用 `servers.sh start` 自动避让，不要动别人。

3. **不要现场敲带箭头/emoji 的 Python 命令。**
   已实测：代码页 936 下 `python -c "print('A \u21b3 B')"` 会抛
   `UnicodeEncodeError: 'gbk' codec can't encode character '\u21b3'` 并**以 exit 1 结束**。
   → 开演前执行 `chcp 65001` + `set PYTHONIOENCODING=utf-8`。
```
