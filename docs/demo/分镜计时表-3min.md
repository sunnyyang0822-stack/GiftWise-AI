# 三分钟 Demo 分镜与计时表（文案审查版）

> 与 [主脚本](../demo-script.md) 一致。仅时间预算，未真人排练、未录屏；不沿用旧版步骤条数量、端口、字节数、候选价格或截图作为新版依据。本轮不制作最终画面。

| 段落 | 计划时间 | 画面工作 | 状态 / 证据门禁 |
|---|---|---|---|
| D1 主场景与披露 | 0:00–0:20 | 追求对象场景；交付版本、实际模式与未知项 | 版本与模式待 PM/QA 回填；虚构人物不作真人数据 |
| D2 明确需求 | 0:20–0:45 | 用户已知信息、预算与准备时间、必要的识别确认 | 新版输入与识别均待验收；未确认的限制不能略过 |
| D3 三方案比较 | 0:45–1:40 | 同屏比较：礼物方向、理由、事实/推断/未知、估价、准备时间 | 核心展示；使用该版本实际输出；人工示例须显著标注 |
| D4 可信保障 | 1:40–2:05 | 一条真实拒绝路径，说明最多一次异常修订的边界 | 不演错误码大全；不得把本地构造拒绝说成模型自然违规 |
| D5 明确选择 | 2:05–2:40 | 用户选择合格方案，选后增强和所选礼物账单 | 可信选择与账单待 QA；未通过不能展示完成态 |
| D6 价值与限制 | 2:40–3:00 | 选择依据、未核实项、最终完成范围 | 不承诺真实库存、送达或对方一定喜欢 |

计划时间合计三分钟，仅来自比赛时限与本稿分配，不是运行耗时或真人计时。加载也计入相应段落，不能用静态稿证明时间足够。D2 的识别等待和 D3 的生成等待需独立测量；QA 锁版后根据实测重新分配，必要时缩短增强部分。

## 模式切换

模式 A/B/C 定义与准入以主脚本为准。A 的真实操作不代表其中每个阶段都接入真实模型；B 必须分开说当前本地操作与旧归档，不能拼成新版链路；C 只供内部产品示意，不能替代比赛核心真实运行。
