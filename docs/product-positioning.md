# 产品定位统一入口

**权威来源：[产品定位与 MVP 体验 · Issue #1](https://github.com/sunnyyang0822-stack/GiftWise-AI/issues/1)。**

产品负责人要求定位集中发布在公开 Issue，方便所有协作 Agent 阅读。因此此文件只保留入口，不再维护第二份完整定位。

所有 Agent 接任务前先读 Issue 正文，再读根目录 `AGENTS.md`、产品需求和相关接口规范。定位变化由 PM 根据产品负责人决定更新 Issue 正文；评论中的建议不自动成为新要求。实现文档与定位冲突时提交 PM 协调，不能各自更改产品方向。

网站与仓库面向人的说明默认简体中文；代码字段和工具名称可保留技术标识符。当前业务能力均待实现和验证。
