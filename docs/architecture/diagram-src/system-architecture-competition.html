设计理由：模型负责给出有依据的方向；硬约束（预算/币种/禁忌/字段/准备时间）由独立代码判定，校验失败项不可选，跨两阶段合计最多一次自动修订。

状态留在服务端最小实现，浏览器只提交输入与选择，避免篡改；当前为单机、无数据库、无账号的最小实现，未做弹性伸缩与故障恢复演练。

成本口径：模型 token 取服务端 workflow_finished.total_tokens（主批次 10 次合计 34,127；含演示与发布验收累计 13 次 / 38,326）；供应商单价未取得真实账单，一律记「未核实」。

事实边界：包装/配色/贺卡阶段未实现；价格与库存未核实；云端未部署、镜像未推仓库；可观测入口已随镜像交付但非默认入口（/metrics 默认 404 且未鉴权）、未上云。虚线部分为目标设计，不得读作已完成。
