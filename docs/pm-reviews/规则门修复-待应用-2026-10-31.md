## 3. `apply.sh` 用法

```bash
# 标准落地（pinned_at 取本机 +08:00 时刻）
bash rulefix/apply-package/apply.sh

# 指定 pinned_at（推荐：写死在评审记录里的那个时刻，便于日后复现）
bash rulefix/apply-package/apply.sh --pinned-at "2026-10-31T09:12:00+08:00"

# 只跑 Python 四条套件，跳过 parity 与接入层（网络/Node 受限时）
bash rulefix/apply-package/apply.sh --skip-js

# 回滚（逐字节还原 4 个文件 + 打印 sha256 与 git status 对照）
bash rulefix/apply-package/revert.sh
```

`apply.sh` 会依次做 10 步并打印 PASS/FAIL 汇总，任一步失败**立即停止并提示 `revert.sh`**（绝不半落地）：
①预检开工前哈希 → ②备份 4 个文件 → ③应用补丁 → ④加 6 条用例（写盘前对真实实现逐条自检）→
⑤重钉基线 → ⑥补契约 §9 → ⑦落地后哈希复核 → ⑧四条套件 → ⑨parity → ⑩接入层 → 汇总。

**没有 git 分支操作**：只用 `git apply` 打工作区补丁，不碰 checkout/switch/branch/stash。
