# 子 Agent 任务提示词（2026-10-31 08:5x）

> 用法：每条提示词**整段复制**给一个子 Agent。它们**互不共享上下文**，所以每条都自带背景与约束。
> 所有提示词末尾都带**统一协议块**（见文末 §0），可直接粘在每条任务后面。
> 分工原则：**读的可以并行，写的必须分文件**；同一文件同一时间只允许一条线动。
