## 7 分钟怎么用

1. **开场 15 秒**：主动交底两个边界（未上云、呈现是 mock）——把最可能被问的两件事先说了，能省下 2 分钟防守时间。
2. **必答四题**（出现概率最高）：**Q4/Q5 价格 → Q21 发布≠上线 → Q18 呈现是 mock → Q7 为什么不上 K8S**。
3. **答不出就用第 3 条应急话术**：直接说"没有实测依据 + 我现在能给的只有 X + 我不编"，然后报《未核实清单》对应条目。
4. **绝不使用《评委问答》附录 B 的 12 句话**（已于本节下方列出最高危的 5 句）。

## 口径纪律（本目录的写法规则）

1. **每个数字必须有出处**：命令可复跑，或"文件:行号"。追不到的写 **未核实 + 为什么现在核不了**。
2. **unknown 不填 0**：金额成本、并发、浏览器端到端延迟都是 `not_measured`／`unknown`，一律不许写 0。
3. **实测 / 已实现未实测 / 未实现 / 未核实** 四态严格区分，不把设计当已实现、不把发布当上线。
4. **发现别人的错 → 只写进 `发现的问题.md`**，不改别人的文件（本线边界：只写 `docs/competition/qa-bank/**`）。
