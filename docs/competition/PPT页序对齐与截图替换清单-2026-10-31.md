## 只读复核当前候选页序的方法

在主工作区根目录执行以下 PowerShell/Python 标准库命令，不写入 PPT：

```powershell
Get-FileHash -LiteralPath 'docs/competition/答辩PPT-GiftWise-最终答辩版-2026-10-31.pptx' -Algorithm SHA256
@'
import zipfile, xml.etree.ElementTree as E
p='docs/competition/答辩PPT-GiftWise-最终答辩版-2026-10-31.pptx'
rns='{http://schemas.openxmlformats.org/officeDocument/2006/relationships}'
pns='{http://schemas.openxmlformats.org/presentationml/2006/main}'
ans='{http://schemas.openxmlformats.org/drawingml/2006/main}'
with zipfile.ZipFile(p) as z:
    pres=E.fromstring(z.read('ppt/presentation.xml'))
    rel={x.get('Id'):x.get('Target') for x in E.fromstring(z.read('ppt/_rels/presentation.xml.rels'))}
    for i,s in enumerate(pres.find(pns+'sldIdLst'),1):
        t=rel[s.get(rns+'id')]
        part=t.lstrip('/') if t.startswith('/') else 'ppt/'+t
        print(i, [x.text for x in E.fromstring(z.read(part)).iter(ans+'t')])
'@ | py -
```

只读 XML 不替代实际打开投影的视觉终检。本轮未运行产品测试、模型调用、截图采集、真人排练或录屏。
