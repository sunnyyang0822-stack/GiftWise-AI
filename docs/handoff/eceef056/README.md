## 最终产品范围

1. 真实网上文字、摘要、教程或案例先进入模型，模型结合关系、喜好与预算做创意延伸；可复用有来源与原观察时间的匿名缓存，不要求每次重抓、照搬商品或逐卡同款 SKU。
2. 推荐成功时返回三个真正可选的文字方案，失败或待澄清不假成功；时间不用于禁选，预算、明确禁忌和结构检查保留，全局最多一次业务修订。
3. 推荐页不抓取或展示网络配图，不启动推荐补图任务。历史参考图接口仍属历史能力，不是现推荐主链。
4. 用户选定礼物后的 AI 生图继续保留：文字先显示，真实图片任务后台执行，按实际状态原位更新；只读查询不重新生成。
5. 纯体验无实体交付不产包装空章或替代占位；实体及混合方案按实际内容展示包装说明、材料和步骤。
