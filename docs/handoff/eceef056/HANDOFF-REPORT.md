## 三、会话、状态、幂等与超时

详细值、源码依据和边界见 [会话与超时](api-b/sessions-timeouts.md)。

- 【实测：源码核对及受控 HTTP】配置请求签发测试 Cookie，实际生产呈现/任务/资产路由执行 owner 校验；跨 owner 的呈现 POST、任务 GET、资产 GET，未知 task 和 pending 资产均被拒绝。没有使用真实用户 Cookie；本轮未单独测试未知 asset。
- 【推算：源码行为】推荐、分析、幂等关联和会话签名等内存状态不是可恢复数据库。重启或多个进程不共享完整任务状态；磁盘存在 task/asset 不表示原会话授权与执行器恢复。
- 【实测：同版受控】实际只执行一次预算修订、repair=1；同一选择重放不增加注入的文字/图片 provider 调用，也不重置 repair；状态 GET 不写任务或创建新付费调用。
- 【源码核对/未做本轮故障注入】业务修订与传输重试分别记录，客户端字段约束见接口契约。本轮没有注入模型传输重试，也没有提交伪造 repair_count 载荷来证明其拒绝。
- 【实测：源码值】普通前端请求 120 秒、服务端公布的客户端建议值 150 秒、模型 120 秒单次调用，是不同含义，不能写成统一总 SLA。解析、状态读取、图片 provider 和前端轮询的单独时限以接口报告逐项表为准。
- 【未测/处置】本冻结版不为材料交接统一改写这些时限；真实多轮供应商延迟、代理超时和冷启动上界需部署验收。若需改变预算、取消或总时限，另提修复、提供新 SHA 和定向结果，不直接在部署机改源码。

## 五、运行依赖、环境与写盘

非秘密模板及源码核对见 [运行依赖](api-b/runtime-dependencies.md)、[env.example](api-b/env.example)；准确存储路径/环境变量、容量、TTL 与重启限制见 [存储与迁移](runtime-c/storage-portability.md)。

【实测】同版 QA 使用 Node `v24.16.0`，Python `3.12.10` 作为 QA 启动整理环境；不据此声称所有更旧 Node、其他平台或整个 Python 服务栈都已验证。前端静态文件无需另行打包；[资源清单](frontend-e/static-assets-manifest.json) 给出必需文件字节与哈希。

【推算/迁移条件】写入路径不是统一外置 `DATA_ROOT`：部分组件限制在当前代码树且拒绝树外链接。默认 SQLite 配置仍有历史 Windows 路径，必须显式配置目标独立库，不能沿用或拷贝原演示库。媒体、匿名素材、审计、账本需要分别配置与挂载；不将挂卷写成任务可恢复或支持多副本。

【推算/已知限制】匿名素材包导入器 `material-bundle.mjs` 的根目录固定为 `E:/黑客松`。它不是所有运行路径都硬编码，但常规 Linux/不同 Windows 根的资料包导入不能原样使用；不得以奇异目录或 symlink 绕过。迁移参数化或目标环境验证由接入 C 与部署侧另单处理，并给新 SHA；不在本交接中暗改冻结代码。可移植公开资料本身及来源/原时间/hash在 [source-data.md](runtime-c/source-data.md)，不含演示数据库或秘密。

【未测】目标 OS、实际 Node/Python 安装、文件权限/磁盘容量、外网、重启、并发费用边界、冷新主题和 Compshare 公网访问尚未验证。
