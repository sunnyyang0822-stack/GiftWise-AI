> ⚠️ **如实记录一个失败**：第一次 `down` 时网络删除**失败**了
> （`Resource is still in use`），因为还有容器在被移除过程中。
> 另外 `lb-one` **没有被第一次 down 清掉**，因为它来自
> `compose/docker-compose.bench.yml` 这个 override 文件——
> `docker compose down` 只会处理**命令行上给出的**那些 compose 文件定义的服务。
> 补上 override 并加 `--remove-orphans` 后清理成功：

```
 Container giftwise-cloudnative-lab-lb-one-1 Stopping
 Container giftwise-cloudnative-lab-lb-one-1 Stopped
 Container giftwise-cloudnative-lab-lb-one-1 Removing
 Container giftwise-cloudnative-lab-lb-one-1 Removed
 Network giftwise-cloudnative-lab_default Removing
 Network giftwise-cloudnative-lab_default Removed
```

**教训（写下来给复跑者）**：用了 override 文件起栈，就必须**用同一组 `-f` 参数**去 down，
否则会留下"孤儿"服务。这也是为什么上一条命令加了 `--remove-orphans`。
